# Geophotos 
**Integrantes:** Agatha Helena, Sofia Marcolongo e Jonas Daniel

O projeto Geophotos é um álbum fotográfico com localização que, ao tirar uma foto, usa como base o GPS para saber o local onde a foto foi tirada. Ele salva a foto em uma lista e mostra o nome da localização embaixo. Ao clicar na foto, as coordenadas do lugar irão aparecer.
